Kinaiya

A companion to talk to. An agent to get things done. Kinaiya pairs a customizable real-time voice character (Converse) with an independent, sandboxed work agent (Agent) inside one local-first workspace—backed by the local or disclosed cloud models you choose.

Architecture

Decoupled dual-loop design.

Model output alone never creates tool authorization; conversation, routing, execution, and state stay cleanly separated.

Converse · :8762

Voice & persona

Handles expressive character dialogue, live speech listening windows, STT/TTS bridges, and curated recall—completely isolated from tool permissions and optional when you only want Agent.

Agent · :8761

Sandboxed execution

Runs coding, repository analysis, file edits, adaptive harnesses, skills, and MCP tools inside bubblewrap + libseccomp2 with explicit owner approval gates.

Decisions · :8763

Advisory turn routing

Classifies finalized turns and live speech windows (ignore, queue, steer, interrupt) without ever speaking as the character or granting execution rights.

Session · :8760

Cryptographic permits

Maintains the monotonic SQLite transcript journal, typed disclosure scopes (local-only by default), and one-use SHA-256 permits bound to exact tool arguments and revisions.
